# [S02] PennyLane ANNNI phase detection demo

**Citation:** PennyLane, “ANNNI Phase Detection,” tutorial_annni (accessed 2026-09-25; live main source). [Source](https://pennylane.ai/qml/demos/tutorial_annni).

**Access/read status:** FULL. Full raw demo.py including comments, code, references. Raw: https://raw.githubusercontent.com/PennyLaneAI/qml/master/demonstrations_v2/tutorial_annni/demo.py

## Claims we will use

Executable Hamiltonian uses competing couplings and open ends. All scan states are generated by dense diagonalization and loaded by StatePrep. There is no implemented VQE ansatz in this demo; use S11 for the paper’s VQE. QCNN trains on analytically labelled axes; anomaly detection trains at one reference point.

## Equations and conventions

Code H=−Σ X_iX_{i+1}+κΣ X_iX_{i+2}−hΣZ_i. Global Hadamards map it to starter ZZ/X, provided boundary conditions match. Displayed Hamiltonian signs disagree with code. QCNN: initial RY, pairwise CNOT+RY, measure alternate wires, conditional RX, pool to two wires, final RY. Labels 0 ferro, 1 antiphase, 2 para, 3 unused. AD uses two layers of RY/CZ/CNOT and final trash rotations; code loss mean(1−⟨Z⟩), differently scaled from displayed half-sum.

## Parameters

N=8; 20×20 grid, κ=0..1,h=0..2, seed123456; 100 epochs; QCNN Adam0.05 and sharpening T=0.5; AD Adam0.1; N/2 central trash wires. JAX64 enabled but eigenvectors cast complex64.

## Limitations and unresolved points

AD parameter counting calls the QCNN builder, giving unused parameters in the displayed N=8 example. OBC versus PBC, precision, class ordering, and loss normalization all need explicit adaptation. StatePrep is not automatically a physically costed ground-state preparation.
