# [S16] Fidelity susceptibility review

**Citation:** S.-J. Gu, “Fidelity approach to quantum phase transitions,” Int. J. Mod. Phys. B 24, 4371–4458 (2010), doi:10.1142/S0217979210056335; arXiv:0811.3127v1. [Source](https://arxiv.org/abs/0811.3127).

**Access/read status:** FULL. All 42 pages of arXiv:0811.3127v1 read, including references.

## Claims we will use

The review develops pure, mixed, reduced and thermal fidelity, scaling examples and numerical methods. The susceptibility claims below use Sec.IV; Sec.V distinguishes reduced-state and thermal fidelity; Sec.VII explicitly recommends using the neighboring ground state as a Lanczos starting vector.

## Equations and conventions

f=1−χFδ²/2+…; χF=lim −2ln(f)/δ²=Σn>0|⟨n|∂λH|0⟩|²/(En−E0)² for a nondegenerate finite ground state. With squared F use −ln(F)/δ². Relevant gap requires a nonzero perturbation matrix element.

## Parameters

Finite step δ must be converged; no universal ANNNI step specified. Table II uses N=20 transverse-field Ising and δh=0.005: at h=1 the finite-step result is 11.87198 versus analytic 11.87500. This is a useful reference check, not an ANNNI parameter recommendation.

## Limitations and unresolved points

Susceptibility need not be singular at infinite-order/BKT transitions. Degeneracy requires subspace treatment. The full reading is of the 2008 v1 preprint, not the later expanded journal layout.

## Rubric relevance

Accuracy, insight, technical sophistication.

For mixed states Gu uses root fidelity tr√(√ρ σ √ρ), whereas PennyLane uses its square. DMRG overlaps require accounting for different renormalized bases (Sec.VII.B); comparing coefficient arrays alone is invalid. The review reports disputed BKT behavior, not a theorem that fidelity always fails. Some displayed intermediate formulas contain apparent typographical issues; use the spectral definition above and numerical step convergence.
