## Claims and current Hamiltonian convention

The original CERN-IT-INNOVATION URL redirects to CERN-QTI. Current `get_H` implements −ΣXX + κΣNNN XX − hΣZ, with `ring=False` by default. For `ring=True`, NN wrap bonds are added for N>2 and NNN wrap bonds for N>4. Exact diagonalization casts the matrix to float32. The DMRG wrapper uses Pauli `Sigmax`/`Sigmaz`, but sets the field coefficient to −max(h,0.1): requests below h=0.1 are replaced by h=0.1. This is unsuitable as an unqualified low-field ground-state reference.

`get_phase` encodes 0=ferro, 1=paramagnet, 2=antiphase; it has no floating label. The autoencoder's trash target is |1⟩, with loss mean((1+Z)/2), whereas the PennyLane demo targets |0⟩. QCNN output grouping also differs; class labels must be translated explicitly.

## Current data and training formats

No precomputed state files or trained weights are bundled in the pinned current checkout; data paths are external/generated, and data and pickle files are ignored. This statement applies to that checkout only: the historical archive below **does contain saved VQEs**.

- Inputs use `[label_]k{k}_h{h}.pkl` and dictionaries indexed by (κ,h). `Diag` stores amplitude vectors of length 2^N; `MPS` stores tensors in left/physical/right order; `Brick` stores `(pp_wire, pp_U)` preparation gates. The MPS-to-circuit conversion uses successive bond-dimension-two layers and reverses/inverts the disentangling gates for preparation.
- `load_all` orders κ on the outer loop and h on the inner loop, requires equal unique-axis lengths, and returns states, four-class one-hot labels, analytical indices and an index map. Some image utilities allocate h-by-κ arrays while indexing κ-by-h; square grids mask axis mistakes.
- `train.h5` contains `params_history` and `loss_history`; `train.json` holds metadata. Slurm QCNN output `data.h5` contains `params` and `predictions`; autoencoder output contains `params` and `compression`. Models otherwise initialize random parameters.

## Current example parameters

The notebooks include an 8-spin QCNN with learning rate 0.01, 500 epochs and T=0.25; the autoencoder example uses three trash qubits, depth 2, learning rate 0.05 and 200 epochs, training at κ=h=0. State-generation batch scripts span N=6–20 with 20×20 grids, MPS bond dimension 64 and brick depth 10. QCNN batch examples use N=8–14 and T∈{0.1,0.25,0.5,1}; autoencoder scripts use N=6–14, N//2 trash qubits and depth floor((N−6)/3)+1. These are source configurations, not executions reproduced here.

## Historical archive: data really are available

The linked Zenodo v1.0.0 archive is 33,889,192 bytes compressed and contains 87 ZIP entries. Under its root `SaverioMonaco-Quantum-Phase-Detection-ANNNI-f0ee370/`, the following extensionless binary files are Python protocol-4 pickles, not text or raw state vectors:

| Archive path under `data/` | Saved size/grid | Boundary condition |
|---|---|---|
| `vqes/ANNNI/N4n100`, `N6n100`, `N8n100`, `N10n100`, `N12n100` | N as named; 10,000 parameter points | Open |
| `vqes/ANNNI/N6n10` | N=6; 100 points | Open |
| `vqes/ANNNI/ring/N6n100`, `N8n100`, `N10n100` | N as named; 10,000 points | Periodic |
| `vqes/standard/N8n100` | Separate standard Ising example | Not an ANNNI dataset |

The serialized `N`, `n_states` and `ring` values were checked through pickle opcodes without executing deserialization. There is **no N=12 periodic VQE file in this archive**. No separately packaged pretrained QCNN/autoencoder weight file was identified; notebooks construct and train those models from saved VQEs. The GitHub releases API listed v1.0.0, v1.1.0 and v2.0.0 with no uploaded release assets; automatic source archives and Zenodo are separate from that asset list.

The historical save schema is a five-item list `[Hs, vqe_params0, vqe_e0, true_e0, circuit_fun]`, or eight items when excited-state parameters and energies are also saved. `Hs` is a `PhaseEstimation.hamiltonians.hamiltonian` object containing Hamiltonians, labels, recycling order and model parameters. `load_vqe` reconstructs the circuit and attaches arrays; states are generated from the parameter vectors. This schema is confirmed from save/load source. The arrays' numerical accuracy and every file's top-level five-versus-eight-item layout were not independently validated.

**Historical sign and axis mapping:** the old builder implements −XX−K NNN XX−LZ with K ranging from 0 to −1 and L from 0 to 2. Thus κ=−K and h=L, followed by a global Hadamard to match starter axes. Grid order is K outer/L inner; n100 means 100 values of each, hence 10,000 states. Stored model parameters are `[N,L,K]`. Labels are two-bit arrays: ferro `[0,1]`, paramagnet `[1,1]`, antiphase `[1,0]`, unknown `[-1,-1]`; only analytically known axes are labeled in the builder.

Saved circuit references identify `circuit_ising` for the N≤10 ANNNI files and `circuit_ising2` for N=12. The former repeats six blocks of Hadamards, a serial CNOT chain and RY rotations, followed by RX rotations (7N parameters); the latter repeats nine blocks followed by RX and RY (11N parameters). Reconstruct these exact archived circuits when interpreting the old weights; they are not interchangeable with a newly chosen ansatz or a schematic paper circuit.

## Limitations and use in this challenge

The historical environment pins PennyLane 0.23.1, JAX 0.3.13 and jaxlib 0.3.10 and references legacy module paths such as `default.qubit.jax`. Current repository requirements include PennyLane 0.40 and NumPy 2.0.2. Neither environment is the challenge's PennyLane 0.44.1/Python 3.14 environment. Direct loading is not verified; a later conversion would need to preserve parameters, circuit, signs, axes, label order and boundaries. The saved energies and states require independent validation against our Hamiltonian before use.

Some ancillary utilities contain author-specific absolute paths; the repository test is an import check, not a physics-validation suite. DMRG finite/open states and archived open-chain VQE states must not stand in for periodic reference states. The lower-field floor and float32 exact path require particular care near degeneracy.
